Elinor re-reloaded 1.0.0, 2026-09-28
----------------------
- New Windows 11 (Fluent) look with light and dark mode; follows the Windows setting by default
- New Settings tab: theme, market log folder, stay on top, update check, overlay opacity
- Compact overlay mode (Ctrl+O): small always-on-top window with item, prices and margin
- Configurable price step for auto copy: smart (EVE 4-significant-digit rule), 0.01 ISK or custom
- Configurable trade hubs per profile, including citadels from the last export
- Settings changes update the displayed numbers immediately
- Moved to .NET 10; ships as an installer or a single portable exe (no .NET install needed either way)
- Fixed crash when another program holds the clipboard during auto copy
- Fixed crash on malformed market log rows
- Fixed freeze when a market log is deleted while it is being read or on profile switch
- Fixed crash on start / save when installed under Program Files
- Fixed market log folder detection with OneDrive-redirected Documents
- Fixed crash deleting a profile or restoring an unknown last profile
- Fixed item name when the log folder path contains a dash
- Fixed numbers in settings being misread on non-English Windows
- Sharp text on high-DPI displays (per-monitor DPI aware)
- Profiles and settings now live in %APPDATA%\Elinor as JSON; profiles and settings from 1.12 are imported automatically
- Errors are logged to %LOCALAPPDATA%\Elinor\logs instead of closing the app
- Update check is off by default
- Removed the retired EVE XML API dependency (EVE.Net)
